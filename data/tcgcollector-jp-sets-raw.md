# TCG Collector — full Japanese set list (453 sets)

Source: Ross's own copy-paste of the rendered `https://www.tcgcollector.com/sets/jp?cardCountMode=anyCardVariant&releaseDateOrder=newToOld&displayAs=list`
page, pasted 2026-08-27 (this session). This is the FIRST TIME this project has had
the real, complete TCG Collector JP set list — everything before this was the vague
"12,823-card gap" estimate from round 9, which was based on TCGdex's own declared
totals, not TCG Collector's fuller catalog.

IMPORTANT: the "0/N  0%" figure after every set entry is Ross's OWN personal
tcgcollector.com collection-completion display (how many of that set's N cards
Ross has marked as owned on that site), NOT this project's DB coverage. Every
single entry shows 0/N because Ross doesn't use tcgcollector.com's own collection
tracker — the N (total card count for the set) is the only number from this page
that's useful for reconciliation purposes, same role TCG Collector's per-set
target played in the zh-cn round-12 reconciliation
(`data/zh-cn-round12-reconciliation.md`).

Organized by era, newest release first, exactly as the page presented it. Each
entry: [set name](url) SHORT_CODE (where TCG Collector shows one — many entries,
especially pre-XY era, have NO short code at all) / release date / price / N (total
card count).

Next step to actually use this: build a `ja`-language equivalent of
`scripts/zh-cn-set-breakdown.ts` (same pattern — paginate `cards` where
`language = 'ja'`, group by `set_id`, print counts) and match those live DB
counts against the per-set N values below, the same way round 12 matched zh-cn.
